02 / Open source

Tools I built for real client problems

Each runs on files or APIs an agency already has. The CI badges are live, straight from GitHub Actions.

Reporting / Data quality

marketing-report-preflight

82 tests

Ten data-integrity checks that run before a client report is sent: GA4 sampling and truncation, missing days, metrics that went silent, consent shifts, duplicate conversions and settings drift. Returns a send or do-not-send verdict and writes the client-facing caveat block.

  • Python
  • FastAPI
  • SQL / SQLite
  • Tailwind
Reporting / Automation

agency-report-builder

23 tests

Pulls GA4 and Search Console for a reporting period, renders a branded HTML report with period-over-period comparison, and exports it to PDF in one command.

  • Python
  • GA4
  • Search Console
  • Jinja
Analytics / Tracking QA

ga4-event-auditor

10 tests

Compares what GA4 actually collects against the tracking plan agreed with the client. Reports parameter coverage as a percentage, catches naming drift and ghost events, and returns a health score you can gate a release on.

  • Python
  • GA4
  • BigQuery
  • Tag Manager
SEO / Monitoring

gsc-coverage-monitor

19 tests

Polls every Search Console property you manage, flags pages that quietly dropped out of search, confirms why with the URL Inspection API, and posts one digest instead of thirty dashboards.

  • Node.js
  • Search Console
  • SQL / SQLite
Paid media / Automation

google-ads-negative-keyword-manager

15 tests

Mines search-term reports for wasted spend, then audits a proposed negative list for conflicts that would block your own converting keywords before anything is uploaded.

  • Python
  • Google Ads
  • pytest
AI / Content

llm-content-brief-engine

22 tests

Turns a keyword into a structured content brief from the live SERP: headings, entities, questions and measured competitor gaps rather than a model's guess at them.
